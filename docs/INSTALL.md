# Install plimsoll on a Mac mini

This is the first-boot checklist for a new Mac. It installs the Homebrew
version, enables the background disk guard, and applies the Time Machine policy
for data that can be recreated from a registry, lockfile, or download.

## 1. Install

Install Homebrew first if it is not already present:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Then install plimsoll:

```bash
brew tap donco-labs/tap
brew trust --formula donco-labs/tap/plimsoll
brew install plimsoll
```

Homebrew 6 requires explicit trust for formulae from third-party taps. The
`--formula` form trusts only plimsoll's formula. Review the formula before
trusting it if this is an unfamiliar machine.

Confirm the installation and take a read-only report:

```bash
plimsoll version
plimsoll report
```

## 2. Configure Time Machine

First configure the backup destination in **System Settings → General → Time
Machine → Add Backup Disk** and let the first backup complete. Keep personal
data in the backup: Documents, Desktop, Downloads, photos, project source,
credentials, and anything that cannot be recreated must remain included.

The exclusion policy covers only rebuildable developer and application data:

```text
~/Library/Containers/com.docker.docker
~/Library/Application Support/com.apple.container
~/Library/Containers/com.inferencer
~/Library/Application Support/Claude/vm_bundles
~/Library/Developer/Xcode/DerivedData
~/Library/Developer/Xcode/iOS DeviceSupport
~/Library/Caches
~/.cache
~/.gradle/caches
~/.npm
~/.ollama
~/.rustup
~/.konan
~/.sdkman
~/.pub-cache
~/fvm
~/go/pkg
~/Library/pnpm
~/.vscode/extensions
~/.cargo/registry
~/.m2/repository
```

The list is maintained in plimsoll rather than copied into this document, so
future installs use the same policy. It intentionally excludes whole cache and
runtime trees: `-p` makes the exclusion persistent when those directories are
recreated.

Run the dry run first:

```bash
plimsoll tm-exclude
```

Review the paths and then apply the policy:

```bash
plimsoll tm-exclude --apply
plimsoll tm-exclude --status
```

`tmutil addexclusion` needs Full Disk Access. If applying the policy fails,
open **System Settings → Privacy & Security → Full Disk Access**, enable your
terminal application, restart that terminal, and run the command again.

The policy is safe to re-run. Paths that do not exist yet are reported as
absent and will be caught on a later run. To remove the exclusions generated by
the policy, preview the undo commands with:

```bash
plimsoll tm-exclude --undo
```

## 3. Install the watchdog

```bash
plimsoll install-guard
plimsoll guard-status
```

The LaunchAgent checks every two hours and once at login. It notifies only for
a new or persistent warning or critical condition. Its log is here:

```text
~/.local/state/plimsoll/plimsoll.log
```

Check it manually at any time:

```bash
plimsoll check
plimsoll report
```

The backup checks distinguish a completed backup from an attempted backup. A
Time Machine job that keeps failing does not count as healthy merely because it
is still enabled.

## 4. Optional menu bar monitor

```bash
brew install --cask swiftbar
mkdir -p "$HOME/Library/Application Support/SwiftBarPlugins"
ln -sf "$(brew --prefix)/opt/plimsoll/libexec/extra/swiftbar/plimsoll.10m.sh" \
  "$HOME/Library/Application Support/SwiftBarPlugins/"
open -a SwiftBar
```

Point SwiftBar at that dedicated `SwiftBarPlugins` folder on first launch. Do
not use `~/Library/Application Support/SwiftBar`; that is SwiftBar's own state
directory.

## Useful first checks

```bash
tmutil isexcluded ~/.cache
tmutil listlocalsnapshots /
plimsoll report
```

Local snapshots are separate from the backup destination. If deleted files do
not return free space, inspect the snapshots before deleting more data:

```bash
plimsoll thin
```

`thin` keeps the newest local snapshot and asks for confirmation. It does not
delete backups from the Time Machine destination.
